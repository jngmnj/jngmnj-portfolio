# 디자인 자료 보관 기준

- 외부 사이트 참고 캡처와 작업 중 화면 캡처: Git에서 제외된 `.codex/local/`
- 직접 작성한 공유용 디자인 가이드: `docs/design/`
- 공유할 문서용 도구: `docs/tools/` (현재 [OG 미리보기](../../tools/og-preview.html))
- 브라우저 프로필, 로그, 커밋·PR 초안, 자격 증명: `.codex/local/`
- 저장소 공용 에이전트·스킬: `.codex/agents/`, `.codex/skills/`

외부 사이트 참고 캡처는 저장소 공유 자료나 앱 배포용 이미지에 포함하지 않는다.
