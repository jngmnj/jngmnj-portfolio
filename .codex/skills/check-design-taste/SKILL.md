# Check Design Taste

Use this skill after UI changes or during frontend review.

## Checklist

- Layout has clear hierarchy, comfortable spacing, and no nested card clutter.
- Borders, shadows, radius, color, and typography match the existing soft product UI.
- Tailwind classes prefer existing patterns and tokens over arbitrary values.
- Hover, focus, active, loading, and disabled states are restrained and readable.
- Korean and English text fit without awkward clipping or overlap.
- Interactive controls have useful labels, visible focus, and touch-friendly hit areas.
- Responsive layouts work across mobile and desktop without text collisions.
