# Make Component

Use this skill for one focused component at a time.

## Steps

1. Read `AGENTS.md` and inspect nearby components before editing.
2. Reuse existing component, Tailwind, and utility patterns.
3. Prefer theme tokens and existing class patterns over arbitrary values.
4. Build accessible controls with semantic elements, labels, keyboard focus states, and touch-friendly hit areas.
5. Check Korean and English text length behavior, including wrapping and truncation.
6. Validate with `git diff`, `git status -sb`, and targeted TypeScript or ESLint checks when runtime code changed.
